# Algorithms

Every hand-implemented algorithm in `packages/dsp` is registered here (AGENTS §11).
Golden vectors live in `packages/dsp/test-data/golden/` and are generated by `tools/golden`
(`pnpm gen:golden`); property tests live beside the unit tests in `packages/dsp/test/`.

| `fftRadix2` | `X[k] = Σ_{n=0}^{N-1} x[n] e^{−j2πkn/N}` computed by bit-reversal permutation followed by log₂N stages of butterflies `t = W_m^j X[a+m/2]`, `X[a+m/2] = X[a] − t`, `X[a] = X[a] + t`, with `W_m = e^{−j2π/m}` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §9.3 (radix-2 decimation-in-time Cooley–Tukey) | O(N log N) time, O(N) space | `packages/dsp/test/fourier/fft.test.ts` | Power-of-two sizes only (non-power-of-two → `RangeError`); precomputed bit-reversal table and N/2 twiddles; empty input → zero-length `Complex`; N = 1 identity; NaN/±Infinity → `TypeError`; never mutates input; golden `test-data/golden/fft.json` (rtol 1e-9, atol 1e-12; N = 2, seeded random N = 1024, bin-centered cosine N = 1024, impulse N = 1024); checked against `dftNaive` at N = 64. |
| `ifftRadix2` | `x[n] = (1/N) Σ_{k=0}^{N-1} X[k] e^{+j2πkn/N}`, returning `Re{x[n]}`, via the conjugate trick `x = Re{conj(FFT(conj(X))) / N}` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §9.3 | O(N log N) time, O(N) space | `packages/dsp/test/fourier/fft.test.ts` | Inverse carries the only scaling (1/N); returns the real part because this library's spectra describe real signals (golden pins `scipy.fft.ifft(X).real`); Hermitian-symmetry validation belongs to the rfft contract; empty spectrum → empty; mismatched `re`/`im` lengths, NaN/±Infinity → `TypeError`; non-power-of-two → `RangeError`; never mutates input. |
| `fftBluestein` | Chirp-z identity `kn = (n² + k² − (k−n)²)/2` with chirp `b[n] = e^{−jπn²/N}`: `X[k] = b[k] Σ_{n=0}^{N-1} (x[n]b[n]) conj(b[k−n])`, evaluated as a length-`m` circular convolution (`m = next_pow2(2N−1)`) via radix-2 transforms (complex FFT from two real ones; inverse via conjugate trick) | Rabiner, Schafer & Rader, *Bell System Technical Journal* 48(5), 1969 (chirp-z transform); Bluestein, *IEEE Trans. | `fft` | `X[k] = Σ_{n=0}^{N-1} x[n] e^{−j2πkn/N}`; dispatcher: power-of-two N → `fftRadix2`, otherwise → `fftBluestein` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §9.3; Bluestein (1970) | O(N log N) time, O(N) space | `packages/dsp/test/fourier/transform.test.ts` | Delegates without touching the samples, so power-of-two output is bit-identical to `fftRadix2` (pinned at N = 1024); empty input → zero-length `Complex`; NaN/±Infinity → `TypeError`; never mutates input. |
| `ifft` | `x[n] = (1/N) Σ_{k=0}^{N-1} X[k] e^{+j2πkn/N}`, returning `Re{x[n]}` via `ifft(X) = conj(FFT(conj X))/N` with `Re{ifft X}[n] = (Re{FFT(Re X)}[n] + Im{FFT(Im X)}[n])/N` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §8.1 | O(N log N) time, O(N) space | `packages/dsp/test/fourier/transform.test.ts` | Arbitrary N (uses the `fft` dispatcher); inverse carries the only scaling (1/N); returns the real part because this library's spectra describe real signals (golden pins `scipy.fft.ifft(X).real`); empty spectrum → empty; mismatched `re`/`im` lengths, NaN/±Infinity → `TypeError`; never mutates input. |
| `rfft` | `X[k] = Σ_{n=0}^{N-1} x[n] e^{−j2πkn/N}` for `k = 0..⌊N/2⌋` only; a real signal satisfies `X[N−k] = conj(X[k])`, so the returned `Complex` holds `⌊N/2⌋+1` bins (N = 0 → empty; N = 1 → one real bin) | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §8.1 (symmetry properties of real sequences) and §9.3; SciPy `rfft` defines the golden vectors | O(N log N) time, O(N) space | `packages/dsp/test/fourier/rfft.test.ts` | Implemented as full complex `fft` followed by slicing the first `⌊N/2⌋+1` bins (documented trade-off; the packed N/2 complex transform is not used); `Im{X[0]} = 0` and, for even N, `Im{X[N/2]} = 0` up to roundoff; empty input → empty spectrum; NaN/±Infinity → `TypeError`; never mutates input; golden `test-data/golden/rfft.json` (rtol 1e-9, atol 1e-12; seeded random N = 1024 and 997, fixed sample N = 1). |
| `irfft` | `x[n] = (1/N) Σ_{k=0}^{N-1} X[k] e^{+j2πkn/N}` with the full spectrum rebuilt from the half-spectrum by Hermitian mirroring: `X[N−k] = conj(X[k])` for `k = ⌊N/2⌋+1..N−1` (the Nyquist bin of an even N is used once) | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §8.1 and §9.3; SciPy `irfft` defines the golden vectors | O(N log N) time, O(N) space | `packages/dsp/test/fourier/rfft.test.ts` | Inverse carries the only scaling (1/N) and returns a real `Float64Array`; requires exactly `⌊N/2⌋+1` re and im bins and a non-negative integer `originalLength` → else `RangeError`; validates the real edge bins `k = 0` and `k = N/2` (even N) with `|Im| ≤ max(1e-12, 1e-9·max|X[k]|)` → else `RangeError` (R5); NaN/±Infinity anywhere → `TypeError`; `originalLength = 0` → empty; never mutates input; golden inverse pinned directly to `scipy.fft.irfft(rfft(x), n = N)` in `test-data/golden/rfft.json`. |
