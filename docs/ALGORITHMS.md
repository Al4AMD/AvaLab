# Algorithms

Every hand-implemented algorithm in `packages/dsp` is registered here (AGENTS §11).
Golden vectors live in `packages/dsp/test-data/golden/` and are generated by `tools/golden`
(`pnpm gen:golden`); property tests live beside the unit tests in `packages/dsp/test/`.

| Algorithm | Formula | Reference | Complexity | Tests file | Notes |
|---|---|---|---|---|---|
| `energyOf` | `E = Σ_{n=0}^{N-1} x[n]²` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §2.1 | O(N) time, O(1) space | `packages/dsp/test/energy.test.ts` | Float64 accumulation even for Float32 input; empty input → 0; NaN/±Infinity sample → `TypeError`; checked against `test-data/golden/energy.json` (rtol 1e-9, atol 1e-12). |
| `averagePowerOf` | `P = E / N`, `N = samples.length` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §2.1 | O(N) time, O(1) space | `packages/dsp/test/energy.test.ts` | `N = 0 → 0` (documented convention, not NaN); otherwise `energyOf(samples) / N`. |
| `dftNaive` | `X[k] = Σ_{n=0}^{N-1} x[n] e^{−j2πkn/N}` (SciPy convention, no scaling) | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §8.1 | O(N²) time, O(N) space | `packages/dsp/test/fourier/dft.test.ts` | Slow reference transform for validating the fast FFT; Float64 internals; phase reduced mod N before sin/cos so large-N roundoff stays below the golden tolerance; empty input → zero-length `Complex`; NaN/±Infinity → `TypeError`; golden `test-data/golden/dft.json` (rtol 1e-12, atol 1e-12). |
| `idftNaive` | `x[n] = (1/N) Σ_{k=0}^{N-1} X[k] e^{+j2πkn/N}`, returning `Re{x[n]}` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §8.1 | O(N²) time, O(N) space | `packages/dsp/test/fourier/dft.test.ts` | Inverse carries the only scaling (1/N); returns the real part because this library's spectra describe real signals (golden pins `scipy.fft.ifft(X).real`); empty spectrum → empty; mismatched `re`/`im` lengths or NaN/±Infinity → `TypeError`. |
| `fftRadix2` | `X[k] = Σ_{n=0}^{N-1} x[n] e^{−j2πkn/N}` computed by bit-reversal permutation followed by log₂N stages of butterflies `t = W_m^j X[a+m/2]`, `X[a+m/2] = X[a] − t`, `X[a] = X[a] + t`, with `W_m = e^{−j2π/m}` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §9.3 (radix-2 decimation-in-time Cooley–Tukey) | O(N log N) time, O(N) space | `packages/dsp/test/fourier/fft.test.ts` | Power-of-two sizes only (non-power-of-two → `RangeError`); precomputed bit-reversal table and N/2 twiddles; empty input → zero-length `Complex`; N = 1 identity; NaN/±Infinity → `TypeError`; never mutates input; golden `test-data/golden/fft.json` (rtol 1e-9, atol 1e-12; N = 2, seeded random N = 1024, bin-centered cosine N = 1024, impulse N = 1024); checked against `dftNaive` at N = 64. |
| `ifftRadix2` | `x[n] = (1/N) Σ_{k=0}^{N-1} X[k] e^{+j2πkn/N}`, returning `Re{x[n]}`, via the conjugate trick `x = Re{conj(FFT(conj(X))) / N}` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §9.3 | O(N log N) time, O(N) space | `packages/dsp/test/fourier/fft.test.ts` | Inverse carries the only scaling (1/N); returns the real part because this library's spectra describe real signals (golden pins `scipy.fft.ifft(X).real`); Hermitian-symmetry validation belongs to the rfft contract; empty spectrum → empty; mismatched `re`/`im` lengths, NaN/±Infinity → `TypeError`; non-power-of-two → `RangeError`; never mutates input. |
| `fftBluestein` | Chirp-z identity `kn = (n² + k² − (k−n)²)/2` with chirp `b[n] = e^{−jπn²/N}`: `X[k] = b[k] Σ_{n=0}^{N-1} (x[n]b[n]) conj(b[k−n])`, evaluated as a length-`m` circular convolution (`m = next_pow2(2N−1)`) via radix-2 transforms (complex FFT from two real ones; inverse via conjugate trick) | Rabiner, Schafer & Rader, *Bell System Technical Journal* 48(5), 1969 (chirp-z transform); Bluestein, *IEEE Trans. Audio Electroacoustics* 18(4), 1970 | O(N log N) time, O(N) space | `packages/dsp/test/fourier/transform.test.ts` | Arbitrary N (the non-power-of-two path of `fft`); chirp phase reduced mod 2N before sin/cos; empty input → zero-length `Complex`; N = 1 identity; NaN/±Infinity → `TypeError`; never mutates input; golden `test-data/golden/fft_arbitrary.json` (rtol 1e-9, atol 1e-12; seeded random N = 6, 997 prime, 1000, 4801 prime); checked against `dftNaive` at N = 5, 6, 7. |
| `fft` | `X[k] = Σ_{n=0}^{N-1} x[n] e^{−j2πkn/N}`; dispatcher: power-of-two N → `fftRadix2`, otherwise → `fftBluestein` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §9.3; Bluestein (1970) | O(N log N) time, O(N) space | `packages/dsp/test/fourier/transform.test.ts` | Delegates without touching the samples, so power-of-two output is bit-identical to `fftRadix2` (pinned at N = 1024); empty input → zero-length `Complex`; NaN/±Infinity → `TypeError`; never mutates input. |
| `ifft` | `x[n] = (1/N) Σ_{k=0}^{N-1} X[k] e^{+j2πkn/N}`, returning `Re{x[n]}` via `ifft(X) = conj(FFT(conj X))/N` with `Re{ifft X}[n] = (Re{FFT(Re X)}[n] + Im{FFT(Im X)}[n])/N` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §8.1 | O(N log N) time, O(N) space | `packages/dsp/test/fourier/transform.test.ts` | Arbitrary N (uses the `fft` dispatcher); inverse carries the only scaling (1/N); returns the real part because this library's spectra describe real signals (golden pins `scipy.fft.ifft(X).real`); empty spectrum → empty; mismatched `re`/`im` lengths, NaN/±Infinity → `TypeError`; never mutates input. |
| `rfft` | `X[k] = Σ_{n=0}^{N-1} x[n] e^{−j2πkn/N}` for `k = 0..⌊N/2⌋` only; a real signal satisfies `X[N−k] = conj(X[k])`, so the returned `Complex` holds `⌊N/2⌋+1` bins (N = 0 → empty; N = 1 → one real bin) | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §8.1 (symmetry properties of real sequences) and §9.3; SciPy `rfft` defines the golden vectors | O(N log N) time, O(N) space | `packages/dsp/test/fourier/rfft.test.ts` | Implemented as full complex `fft` followed by slicing the first `⌊N/2⌋+1` bins (documented trade-off; the packed N/2 complex transform is not used); `Im{X[0]} = 0` and, for even N, `Im{X[N/2]} = 0` up to roundoff; empty input → empty spectrum; NaN/±Infinity → `TypeError`; never mutates input; golden `test-data/golden/rfft.json` (rtol 1e-9, atol 1e-12; seeded random N = 1024 and 997, fixed sample N = 1). |
| `irfft` | `x[n] = (1/N) Σ_{k=0}^{N-1} X[k] e^{+j2πkn/N}` with the full spectrum rebuilt from the half-spectrum by Hermitian mirroring: `X[N−k] = conj(X[k])` for `k = ⌊N/2⌋+1..N−1` (the Nyquist bin of an even N is used once) | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §8.1 and §9.3; SciPy `irfft` defines the golden vectors | O(N log N) time, O(N) space | `packages/dsp/test/fourier/rfft.test.ts` | Inverse carries the only scaling (1/N) and returns a real `Float64Array`; requires exactly `⌊N/2⌋+1` re and im bins and a non-negative integer `originalLength` → else `RangeError`; validates the real edge bins `k = 0` and `k = N/2` (even N) with `|Im| ≤ max(1e-12, 1e-9·max|X[k]|)` → else `RangeError` (R5); NaN/±Infinity anywhere → `TypeError`; `originalLength = 0` → empty; never mutates input; golden inverse pinned directly to `scipy.fft.irfft(rfft(x), n = N)` in `test-data/golden/rfft.json`. |
| `window` | Periodic window (denominator `L`, SciPy `sym=False`) for `n = 0..L−1`: rect `w[n] = 1`; hann `0.5 − 0.5·cos(2πn/L)`; hamming `0.54 − 0.46·cos(2πn/L)`; blackman `0.42 − 0.5·cos(2πn/L) + 0.08·cos(4πn/L)` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §7.2; Harris, *Proc. IEEE* 66(1), 1978; SciPy `scipy.signal.windows.*` (`sym=False`) defines the golden vectors | O(L) time, O(L) space | `packages/dsp/test/fourier/windows.test.ts` | STFT/overlap-add variant; periodic hann at 50 % hop satisfies COLA (tested at L = 64, hop = 32); `kind` is a TS union (`"rect" \| "hann" \| "hamming" \| "blackman"`); integer `length ≥ 2` → else `RangeError` (NaN/±Infinity included); returns a fresh `Float64Array`; golden `test-data/golden/windows.json` (rtol 1e-9, atol 1e-12; L = 64 and L = 2 cases). |
| `windowSymmetric` | Same four window formulas with denominator `L−1` (SciPy default `sym=True`) | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed. §7.2 (symmetric windows for FIR design); SciPy `scipy.signal.windows.*` (`sym=True`) defines the golden vectors | O(L) time, O(L) space | `packages/dsp/test/fourier/windows.test.ts` | FIR filter-design variant; `w[n] = w[L−1−n]` (tested, even and odd L); same `length ≥ 2` → `RangeError` contract; returns a fresh `Float64Array`; golden `test-data/golden/windows.json` pins all four kinds at L = 64 directly against `sym=True` values, plus the symmetric kaiser case. |
| `kaiser` | Symmetric Kaiser window: `w[n] = I0(β·√(1 − (2n/(L−1) − 1)²)) / I0(β)`, `n = 0..L−1` | Kaiser, "Nonrecursive digital filter design using the I0-sinh window function", *Proc. IEEE ISCAS*, 1974; SciPy `scipy.signal.windows.kaiser` defines the golden vectors | O(L) time, O(L) space | `packages/dsp/test/fourier/windows.test.ts` | `β = 0` → all ones; `I0` is even so `kaiser(L, −β) = kaiser(L, β)` (tested); peak ≤ 1 (roundoff tolerance) and non-negative; integer `length ≥ 2` → else `RangeError`; non-finite `β` → `TypeError`; golden `test-data/golden/windows.json` (L = 64, L = 2 with β = 8.6). |
| `i0` | Zeroth-order modified Bessel function of the first kind via its power series `I0(x) = Σ_{k=0}^{29} (x²/4)^k / (k!)²`, accumulated with the recurrence `t_k = t_{k−1}·(x²/4)/k²` | Abramowitz & Stegun, *Handbook of Mathematical Functions*, eq. 9.6.12; SciPy `scipy.special.i0` defines the golden vectors | O(1) time, O(1) space | `packages/dsp/test/fourier/windows.test.ts` | 30-term truncation accuracy: ≈1e-15 relative for `|x| ≤ 12` (golden probe range), ≈4e-13 at `|x| = 20`, degrading beyond `|x| ≈ 20` (8.7e-7 at `x = 30`); `I0(0) = 1` and evenness are exact properties (tested); non-finite `x` → `TypeError`; golden probe values for `x ∈ {0, 1, 8.6, 12}` from `scipy.special.i0`. |
| `stft` | `M = ceil(N/H)`; frame `m` starts at `mH`, `y_m[n] = x[mH+n]` for `n = 0..L−1` (zero beyond `N`), zero-padded from `L` to `F`; `X_m[k] = Σ_{n=0}^{L−1} w[n]·y_m[n]·e^{−j2πkn/F}` for `k = 0..F−1`, **unnormalized** (no `1/F`, no window-sum scaling) | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §10.3; SciPy `scipy.signal.stft` (`scaling="spectrum"`, `boundary=None`, `padded=False`) divided by `window.sum()` defines the golden vectors | O(M·F·log F) time, O(M·F) space | `packages/dsp/test/fourier/stft.test.ts` | Periodic window for overlap-add; last frame zero-padded; `frameLengthSamples`, `hopLengthSamples`, `fftLengthSamples` integers with `L ≥ 1`, `H ≥ 1`, `F ≥ L` → else `RangeError`; `window.length = L` → else `RangeError`; NaN/±Infinity input or window → `TypeError`; empty input → no frames; `StftResult` carries `window` (copy), `originalLengthSamples` and the frame/hop/FFT metadata; golden `test-data/golden/stft.json` pins every frame for N = 4096 sine (hann 256/hop 64/FFT 256 and 512, rect 256/hop 256/FFT 256) with rtol 1e-9, atol 1e-12. |
| `istft` | Inverse `x_m[n] = (1/F)·Re{Σ_{k=0}^{F−1} X_m[k]·e^{+j2πkn/F}}`, then windowed overlap-add with per-sample squared-window normalization: `out[n] = Σ_m w[n−mH]·x_m[n−mH] / Σ_m w[n−mH]²`; `out[n] = 0` where the denominator is 0 (R16); trimmed to `originalLengthSamples` | Oppenheim & Schafer, *Discrete-Time Signal Processing*, 3rd ed., §10.4 (overlap-add synthesis); Griffin & Lim, *IEEE Trans. ASSP* 32(2), 1984 (weighted overlap-add); SciPy `scipy.signal.istft` uses the same window-energy normalization | O(M·F·log F + M·L) time, O(N) output space | `packages/dsp/test/fourier/stft.test.ts` | Weighted overlap-add cancels the analysis window wherever `Σ w² > 0`; requires `H ≤ L`, `F ≥ L`, each frame to hold exactly `F` re/im bins, and `originalLengthSamples` a non-negative integer ≤ the covered length → else `RangeError`; zero frames → empty; NaN/±Infinity window or spectrum → `TypeError`; `stft` with `H > L` is allowed but `istft` rejects it (perfect reconstruction is undefined); golden pins `istft(stft(x))` directly to the original samples (rtol 1e-9, atol 1e-12); property tests cover rect/hop = L (≤1e-10), hann/H = L/4 and L/2 (≤1e-9 on nonzero-energy samples, 0 elsewhere), linearity, short input, and R16. |
